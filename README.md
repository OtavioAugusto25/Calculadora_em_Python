Calculadora em Python

Calculadora simples de terminal feita em Python. O usuário digita dois números, escolhe uma operação e recebe o resultado.

Funcionalidades
Adição
Subtração
Multiplicação
Divisão (com tratamento para divisão por zero)
Mensagem de erro para opção inválida

Exemplo de uso

Digite seu primeiro valor: 10
Digite seu segundo valor: 5
1. Adição
2. Subtração
3. Multiplicação
4. Divisão
Opção: 4
O resultado é: 2.0


Estrutura do código

valores_usuario(): lê os dois números digitados pelo usuário.
equacoes(): mostra o menu e lê a opção escolhida.
operacao_matematica(a, b, opcao): realiza o cálculo e exibe o resultado.
